# WeLoveLyrics — versión para subir sin carpetas

Esta versión está preparada para que todos los archivos necesarios queden en la raíz del repositorio de GitHub. No tienes que crear carpetas `css`, `js` ni `data`.

## Archivos que debes subir
- `index.html`
- `styles.css`
- `app.js`
- `songs.js`

`demo-song.json` es solo un archivo de ejemplo opcional; no se necesita para que la página cargue.

## Actualizar GitHub
1. Descomprime el ZIP.
2. Abre tu repositorio de GitHub y entra a la raíz.
3. Sube los cuatro archivos necesarios y reemplaza los anteriores cuando GitHub te lo indique.
4. En GitHub Pages, configura `main` y `/ (root)`.

## Aviso de seguridad
Esta página es un prototipo estático. El Creator Studio usa un acceso de demostración en el navegador y no es autenticación segura; las canciones guardadas localmente no se comparten automáticamente. Los estudiantes no tienen formulario para subir canciones. Para publicar canciones para todos, los colaboradores deben actualizar el catálogo `songs.js` en GitHub.
